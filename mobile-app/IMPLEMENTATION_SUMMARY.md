# ETA-Sync Mobile App - Implementation Summary

## Overview

Complete Flutter mobile application for the ETA-Sync research project. The app captures real-time IMU sensor data (accelerometer and gyroscope) and camera frames, streaming them to a FastAPI server for temporal alignment research using Dynamic Time Warping (DTW) and Cross-Attention mechanisms.

## Data Format

### IMU Data Sent to `/imu` Endpoint:
```json
{
  "timestamp": 1709874022.123456,
  "ax": 0.12,
  "ay": 0.034,
  "az": 9.81,
  "gx": 0.001,
  "gy": 0.0002,
  "gz": 0.0015,
  "mode": "sync"
}
```

### Camera Frame Sent to `/frame` Endpoint:
```json
{
  "timestamp": 1709874022.123456,
  "frame_id": 1234,
  "resolution": "640x480",
  "data": "base64_encoded_jpeg_bytes",
  "mode": "sync"
}
```

## Known Limitations

- Async delay is hardcoded to 200ms (can be configured in app_config.dart)
- Camera frames are JPEG compressed (not raw)
- No local data persistence (data only sent to server)
- No data validation on client (validation done server-side)
- Assumes server is available during streaming
